Data quality findings

This project's engineering value lives here as much as in the numbers above — each finding below was investigated to its root cause, not just worked around.

Metadata bug in PySUS's remote catalog

TUBEBR16.parquet existed in the catalog but returned empty — root cause: a null group_id excluding the file from any query filtered by condition. Worked around via a query without the group filter.

Missing-value sentinel, three sources, three formats

SINAN-TB uses "0", IBGE/SIDRA uses "...", SIM uses the UF+0000 pattern — same semantic idea ("not identified"), three different conventions, each identified and handled explicitly.

Irregular SIM coverage

19 of 270 state×year combinations (7%) have no published file, spread across 8 states with no single pattern — treated as a declared limitation (status_cobertura_sim), not backfilled from an alternative source.

A hypothesis tested and partially refuted

4 cases where SINAN > SIM in the reconciliation aren't explained by SIM consolidation lag, as expected — reported as an unresolved residual anomaly, not forced to fit the narrative.
